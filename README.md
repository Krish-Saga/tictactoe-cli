# Tic-Tac-Toe Cli 🎮

## About 
    
    This project uses a minimax algorithm for ai bot that plays against the player later it will be multiplayer like you can play with friend in terminal and many more cool things to introduce a cool ui and other things that's it for now

## Installation

Clone the repository:

```bash
git clone https://github.com/Krish-Saga/tictactoe-cli.git
cd tictactoe-cli
```
or if you have rust installed you can use :

```bash
cargo install --git https://github.com/Krish-Saga/tictactoe-cli
```

## Running game 
    
```bash
cargo run
```
